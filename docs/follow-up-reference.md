# مرجع المتابعة

التبويب فارغ أول مرة. لا توجد بيانات شخصية في المستودع. احفظ المرجع من «استيراد مرجع / تحديث المرجع»، وراجع المعاينة ثم اعتمدها. يدعم TXT وMarkdown وJSON. الاستيراد النصي محافظ: يحتفظ بالنص كاملًا في «النص الأصلي»، ويستخرج فقط عناوين الأيام ذات تاريخ ISO واضح YYYY-MM-DD (بما فيه الأرقام العربية). لا يستنتج سنة أو تاريخًا مبهمًا ولا يولد ملخصات. استخدم تعديل التقييم لإكمال الحقول؛ النص غير المصنف يحتاج تقسيمًا يدويًا أو تحويلًا خارجيًا إلى JSON.

البيانات محلية فقط في `waqti-follow-up-v1:<uid>` أو `guest`، خارج state وFirebase؛ لكل حساب نطاق مستقل. ليست مشفرة على الجهاز، وقد يمحوها حذف بيانات المتصفح. لا تنتقل تلقائيًا بين الأجهزة؛ صدّر نسخة. لا يجري استدعاء AI أو إرسال المرجع لأي جهة. الدخول لا ينقل مرجع الضيف إلى الحساب تلقائيًا.

## التحديث بواسطة ChatGPT

1. اختر «تصدير التطبيق مع المرجع» من التبويب. التصدير العادي يظل بدون المرجع.
2. أرفق JSON في المحادثة واكتب «مرجع المتابعة». يتضمن `followUpReference` تعليمات المنهج والبنية وbaseRevision. قواعد المستخدم داخل sections والنص الأصلي تظل محفوظة.
3. اطلب JSON كاملًا، ثم استورده من زر تحديث المرجع. راجع الأيام والملخصات والتعارضات قبل الاعتماد. التعليمات تساعد النموذج، ولا تضمن التزام كل نموذج بها.
4. لا يغير تحديث المرجع مهام التطبيق أو خاناته. استعادة نسخة التطبيق الكاملة من الإعدادات تستعيد بيانات التطبيق بعد تأكيدها، ثم تعرض معاينة المرجع بصورة مستقلة. يمكن إلغاء المرجع دون إلغاء استعادة بيانات التطبيق.

## البنية

`schemaVersion:1`, معرف ثابت `id`, `revision`, `baseRevision`, `updatedAt`, `updateInstructions`, وخرائط `days`, `periods`, `sections`. كل سجل له `id` وتاريخ `updatedAt`. القيم النصية: summary, positives, improvements, advice, patterns, coverage, metrics, exceptions, limitations, sources. الحالات: complete, partial, temporary, none. تجارب التحسين تدعم experimentState: proposed, approved, running, completed, stopped، ولا تُعتمد تلقائيًا. الحقول الإضافية داخل السجلات محفوظة.

معرفات الفترات: YYYY، YYYY-Q1..Q4، YYYY-MM، YYYY-MM-S1..S6. تغيير يوم يدويًا يضع علامة needsReview على ملخصات القسم والشهر والربع والسنة؛ لا يعيد توليد التقييمات تلقائيًا. استيراد ملخص محدث معه يزيل الحاجة إلى هذه العلامة بحسب محتوى الملف. البحث يشمل الأيام والفترات والأقسام.

الدمج يحتفظ بالسجلات الغائبة عن الملف، ويحمي التعديلات اليدوية باختيار صريح لكل تعارض. الإصدار الأقدم أو المرجع المختلف يتطلب إقرار اختلاف الإصدار. إعادة نفس JSON لا تنشئ سجلات أو مراجعات إضافية. يُرفض تغير المرجع أثناء المعاينة أو تغير الحساب قبل الاعتماد. آخر ثماني نسخ محفوظة محليًا، والاسترجاع يعرض معاينة تتضمن حذف السجلات التي أُضيفت بعدها، مع حماية التعديلات اليدوية بخيارات التعارض. الحذف يمحو النسخ السابقة أيضًا بعد تأكيد.

الإصدار 1 هو الإصدار الأول، ويرفض الإصدارات غير المدعومة بدل تحويلها بصمت. أي إصدار مستقبلي يحتاج ترحيلًا صريحًا. اختبارات الميزة اصطناعية بالكامل: `npm test` و`npm run test:follow-up:browser`.
