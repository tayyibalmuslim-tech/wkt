# إعادة تصميم واجهة وقتي — المرحلة 6

الهدف: **سهولة الاستخدام** و**تصميم يحفّز على الإنجاز** مع الحفاظ على كل البيانات والمنطق والاختبارات.

## ما الذي تغيّر

| الجزء | التغيير |
| --- | --- |
| الهوية | خط IBM Plex Sans Arabic مضمّن محليًا (رخصة OFL في `vendor/fonts`)، ولوحة ألوان «ليل وفجر»: نيلي هادئ للأساس وذهبي فجري للتقدم. |
| المظهر الليلي | ثلاثة أوضاع: تلقائي حسب الجهاز، فاتح، ليلي. زر التبديل في رأس الصفحة، والاختيار محفوظ على الجهاز (`waqti-theme`). |
| نبض اليوم | بطاقة أعلى كل صفحة: الصلاة الحالية والوقت المتبقي على التالية، وكم مضى من يومك حتى المغرب، وحلقة إنجاز اليوم (المهام + مهام الصلاة)، وتذكير يومي قصير. |
| سجّل الآن | زر في النبض يفتح تسجيل خانة «الآن» مباشرة من أي صفحة، ويعرض «المطلوب الآن» إن كان مخططًا. |
| الهاتف | شريط التبويبات انتقل لأسفل الشاشة (أقرب للإبهام)، والصلوات الخمس تظهر معًا بدل التمرير الأفقي، وكل الأزرار 40px على الأقل. |
| الكمبيوتر | شريط علوي مدمج (48px) بتبويبات على شكل مفاتيح مجمّعة، وأيقونة لكل تبويب بما فيها «مرجع المتابعة». |
| الإعدادات | العنوان أولًا ثم تذكير القلب، وخانة التفعيل لم تعد تتداخل مع الأزرار. |
| الألوان الثابتة | تحويل الألوان المكتوبة يدويًا في CSS إلى متغيرات حتى تتبع كل الصفحات المظهر المختار. |

## الملفات

- جديد: `design.css` (طبقة التصميم، تُحمّل أخيرًا)، `shell.js` (المظهر ونبض اليوم، عرض فقط ولا يكتب بيانات)، `vendor/fonts/*`.
- معدّل: `index.html` (رأس الصفحة والأيقونات والخط)، `style.css` و`categories.css` و`follow-up.css` (ألوان إلى متغيرات فقط)، `app.js` (ترتيب صفحة الإعدادات وعنوانها).
- لم يتغير: التخزين، المزامنة، قاعدة البيانات، منطق المهام والخانات.

## إصلاحات الاختبارات

كانت 3 اختبارات وحدة واختبار متصفح فاشلة **قبل** هذا العمل لأنها تتوقع سلوكًا قديمًا تغيّر عمدًا في ميزات لاحقة:

- عدد عناصر «المزيد» في الهاتف صار 4 بعد إضافة «مرجع المتابعة».
- مهام الفترة صارت مجمعة حسب الفعل، و«كل مهام اليوم» قائمة مرتبة مسطحة.
- الفائتة مجمعة حسب الفعل مع عنوان للمهمة الرئيسية.
- زر «تحديد عدة مهام» انتقل للتنقل (commit `0cd1bdf`).

وحُدّثت اختبارات المتصفح لتتوقع شريط الهاتف في الأسفل. `test:follow-up:browser` صار يقبل `WKT_CHROMIUM_EXECUTABLE` مثل بقية الاختبارات.

## نتيجة التحقق

- `npm test`: كل المجموعات ناجحة.
- `npm run test:browser`: كل المجموعات ناجحة، ومنها فحص 27 صفحة/حجم للتباين وأهداف اللمس وRTL، وأُعيد نفس الفحص في المظهر الليلي ونجح.
- `test:prayer-plans:browser` و`test:follow-up:browser` و`test:heart:browser`: ناجحة.

## حدود ومخاطر

- لم يُجرّب على هاتف حقيقي أو Safari؛ الفحص على Chromium بمحاكاة الأحجام.
- ألوان الأقسام الافتراضية (الفاقعة) بيانات وليست تصميمًا، فلم تُغيَّر. يمكن تعديلها من «الأقسام والأفعال».
- النبض يُحسب من مواقيت الجهاز والموقع المحفوظ؛ لو كانت المواقيت غير مضبوطة سيظهر الوقت المتبقي غير دقيق.

# المرحلة 7 — تحسين تبويب «يومي»

| الجزء | التغيير |
| --- | --- |
| خطة الفترة | بدل 4 أسطر نصية (المخطط / تم / المتبقي / الزائد) يتكرر فيها كل فعل 3 مرات: لوحة واحدة فيها نسبة الإنجاز وشريط عام، وصف لكل فعل (الاسم، شريط بلونه، المنجز / المخطط، الباقي أو «اكتمل»)، ثم «خارج الخطة» كشارات مع تمييز الوقت الضائع بالأحمر. |
| مكان الخطة | انتقلت فوق الخانات بدل أسفل 64 خانة، فتظهر دون تمرير. |
| بطاقات الصلوات | شريط صغير لنسبة تنفيذ خطة كل صلاة، وشارات الأفعال المخططة أوضح، ومحتوى البطاقة يبدأ من أعلى بدل التوزع على ارتفاعها. |
| الخانات | لون الفعل صار خلفية هادئة مع حافة بلونه الكامل بدل التعبئة الفاقعة، والخانات الفارغة تعرض الوقت فقط (علامة + تظهر عند المرور)، وارتفاع أقل مع الحفاظ على 40px للمس. |
| رأس اليوم | ملخص التسجيل كشارات موحدة. |

الملفات: `day.css` (جديد، يحمّل بعد design.css)، `app.js` (ملخص الخطة، مؤشر البطاقة، متغير لون الخانة `--slot`)، `index.html`، وتحديث اختبارَي ملخص الخطة ولون الخانة. لا تغيير في البيانات أو المزامنة.
