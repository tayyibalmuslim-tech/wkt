# وقتي

تطبيق عربي لإدارة الوقت حول الصلوات، مع ٩٦ خانة ربع ساعة ومزامنة Firebase.

## التشغيل

ملفات التطبيق في جذر المستودع، بدون خطوة بناء. شغّل خادمًا محليًا مثل:

```sh
python3 -m http.server 8080
```

أو استخدم GitHub Pages من فرع `main` ومجلد `/ (root)`.

## Firebase

- فعّل Email/Password من Authentication.
- أضف `tayyibalmuslim-tech.github.io` إلى Authorized domains عند استخدام GitHub Pages.
- انشر `database.rules.json` في Realtime Database. يحتوي الملف على القواعد المدمجة للتطبيقات الموجودة ووقتي.
- قواعد المسارات الأربعة القديمة تسمح بالقراءة والكتابة العامة كما في إعداداتك السابقة؛ مسار `waqti/users/{uid}` خاص بكل حساب.
- من «الحساب والمزامنة» سجّل دخولك، ثم اختر نقل بيانات الجهاز السابقة عند الحاجة. التخزين المحلي منفصل لكل نطاق، لذا انقل البيانات بالحساب أو التصدير والاستيراد عند الانتقال من رابط Sites.

## الخصائص

اليوم من المغرب إلى المغرب، تقويم هجري، مواقيت محسوبة للقاهرة أو الموقع المختار، عرض ١٢ ساعة، قوائم الصلوات، مهام متكررة، أفعال بألوان، نسخ احتياطي ومزامنة مع اكتشاف التعارض.

المكتبات الخارجية محلية في `vendor/`: Adhan 4.4.6 وFirebase compat 12.4.0. لا تُحفظ كلمات المرور في بيانات التطبيق.

## ملاحظات الخانات وتسجيل الفترات
اضغط الفعلي أو المطلوب لاختيار فعل وإضافة ملاحظة ثم احفظ. زر «تسجيل فترة كاملة» يتيح اختيار البداية والنهاية بنظام 12 ساعة وتطبيق نفس الفعل والملاحظة على كل أرباع الساعة في الفترة. النهاية غير مشمولة، لذا من 5 إلى 7 يسجل 8 خانات. يمكن حفظ ملاحظة وحدها، وإفراغ التسجيل يمسح الفعل وملاحظته في الجزء المختار فقط.
